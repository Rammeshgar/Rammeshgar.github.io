03 / Approach
Move or click the field

How I work.

I start with the job the software needs to do, rather than a list of technologies. I use the following questions to make decisions and test the outcome.

01

What needs to happen?

Define the expected result and constraints before choosing a tool.

In the currency app: verify that the converted amount changes with the input.
02

Which parts depend on each other?

Expose handoffs and dependencies so that the workflow can be changed and checked.

In Seneschal: a task can be held until its selected prerequisites finish.
03

How can I check the outcome?

Test the paths that matter, retain evidence, and make failures visible.

In the monitor: a failed browser run links back to its log and screenshot.
