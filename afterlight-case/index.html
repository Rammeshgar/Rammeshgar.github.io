Case 05 / Desktop applicationWindows · Classic & Cinema

Afterlight.Beyond a still
desktop.

I wanted a wallpaper that responds to small interactions rather than looping a video. Afterlight is an offline Windows app with nine scenes, from a rainy city canal to a lunar station. I designed the experience and used AI to help build the renderer and desktop integration.

03 / From artwork to wallpaper

The scene is only half the work.

Keeping a wallpaper behind the desktop icons is different from drawing it in a browser. I worked on both, including how to pause rendering and recover the app's own desktop layer.

  1. Windows host

    The native application manages its own wallpaper layer, the tray controls and the local settings. It also handles pause and bounded recovery.

  2. Local WebView

    WebView2 hosts the renderer. It loads packaged assets and advances the world from local state, actions and a single animation clock.

  3. Active scene

    The selected world renders at 960 × 540, including its local layers. Changing worlds disposes the old scene; 4K still export scales the image rather than rendering native 4K animation.

Playback

Pause is a real state.

I included motion controls, a Stillness mode and safeguards for when the renderer should stop. Optional music response starts off. If enabled in the desktop app, it analyses the default Windows audio output locally, which can include notifications and calls. No microphone, capture files or music service are needed.

Installation

Just the desktop requirements.

The target is Windows 10/11 x64 with .NET Framework 4.8 and WebView2. After those prerequisites, the app does not require Docker, Node, API keys or a network connection. The current installers are unsigned; review the release information before running them.

04 / Recorded checks

What I checked.

These counts come from the original Afterlight 1.8 offline test record. They are not a live reading, a separate Cinema certification or proof of a clean Windows installation.

9

Scenes checked

Each scene ran through 12 palette/weather combinations, one-loop, pause, hidden, Stillness and recovery checks.

24

Imported-world actions

Each changed canvas pixels in the test, and the 24 corresponding hotspot centres were routed.

44

Isolated installer checks

Packaging and installer actions were checked in an isolated setting. This was not a fresh desktop installation on another PC.

What remains unverified.

Earlier native runs cover short desktop placement and recovery checks on this development machine. The separate nine-world 1.8 native check did not finish. I have not established overnight stability, independent multi-monitor behaviour, ARM compatibility or clean installation on a second PC. Desktop placement also relies on Windows behaviours that can change.
